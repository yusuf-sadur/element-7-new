# Brand fonts

## Canela (hero — all text in home hero)

Installed from `Canela Family` (OpenType):

- `Canela-Light.otf` (300)
- `Canela-Regular.otf` (400)
- `Canela-LightItalic.otf` (300 italic)
- `Canela-Medium.otf` (500)

Optional WOFF2 versions with the same base names are used if added later.

## Neue Haas Grotesk (all headings)

Add when available:

- `NeueHaasGrotesk-Light.woff2` (300)
- `NeueHaasGrotesk-Roman.woff2` (400)
- `NeueHaasGrotesk-Medium.woff2` (500)
